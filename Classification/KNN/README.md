# KNN

## Settings

| symbol | shape | meaning | 
| :--- | :--- | :--- | 
| $n$ | $\mathbb{R}$ | the number of samples |
| $d$ | $\mathbb{R}$ | the number of dimensions of a data |
| $X$ | $\mathbb{R}^{n\times d}$ | the sample data |
| $y_i$ | $\mathbb{R}$ | the classification label |
| $y$ | $\mathbb{R}^n$ | the labels vector |
